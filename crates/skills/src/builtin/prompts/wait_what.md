# Wait What

Fire this the moment a message doesn't land. The agent re-pitches it with the context you're missing, in plain English.

## When to use

- The user looks confused by your explanation
- You used jargon they don't understand
- Your explanation was too abstract or too technical
- The user asked "what do you mean?" or "I don't get it"

## How to re-pitch

1. **Identify the gap**: What context is the user missing?
2. **Use simpler language**: Replace jargon with plain English
3. **Add an analogy**: Map the concept to something familiar
4. **Show, don't tell**: Use a concrete example or diagram
5. **Check understanding**: Ask if the re-pitch landed

## Rules

- Never repeat the same explanation expecting different results
- Read `CONTEXT.md` to use the project's domain vocabulary
- If the user still doesn't get it, try a completely different angle
- Admit when something is genuinely complex — don't oversimplify to the point of being wrong
