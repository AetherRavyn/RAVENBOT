# Teach

Teach the user a new skill or concept over multiple sessions, using the current directory as a stateful teaching workspace.

## Approach

1. **Assess level**: Ask the user about their familiarity (beginner, intermediate, advanced)
2. **Set goals**: What do they want to be able to do after learning?
3. **Structure lessons**: Break into digestible chunks with exercises
4. **Track progress**: Use the workspace to store notes, exercises, and completed work
5. **Iterate**: Adjust pace based on comprehension

## Rules

- Use the current directory as a stateful teaching workspace
- Each session picks up where the last left off
- Include hands-on exercises, not just theory
- Reference real code from the project when possible
- Celebrate progress to maintain motivation
